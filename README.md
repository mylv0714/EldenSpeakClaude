# EldenSpeak
# https://eldenspeakclaude.onrender.com/

오픈 월드 도시를 돌아다니며 AI 캐릭터와 **진짜 영어로 대화하는** 영어회화 게임입니다.
GTA 2 스타일의 탑다운 도시에서 걷고, 운전하고, 일하고, 연애하며 — 모든 미션을 말로 해결합니다.

- **웹**(데스크톱·모바일 브라우저)과 **Android**(Capacitor)에서 실행
- 음성 인식(마이크) 또는 타이핑으로 대답, 캐릭터는 억양·성별별 음성으로 말함
- 매 턴마다 AI 채점(점수·교정·원어민 표현), 대화가 끝나면 AI 선생님의 피드백

## 주요 기능

### 도시와 미션
- **스토리**: 공항 입국 심사 → 호텔·은행 → 취업 면접 → 사건 해결 → 투자 피칭 → TV 토크쇼 출연까지 10장의 메인 스토리
- **장소 미션**: 카페, 은행, 병원, 호텔, 레스토랑 등 도시 곳곳의 상황별 대화
- **거리 이벤트**: 길 묻는 관광객, TV 인터뷰, 사기꾼, 접촉 사고, 경찰 검문
- **아르바이트**: 택시 운전, 피자 배달
- **로맨스**: 미선과의 만남 → 데이트 → 연인 (PG-13)
- **워드 코인**: 도시 곳곳의 관용구 수집

### 대화
- **1인칭 대화 씬**: 장소별 배경(카페·은행·거리·택시 안·현관 등) 앞에 상대가 서 있고, 게임 시간에 따라 낮·노을·밤이 바뀝니다. 캐릭터는 숨 쉬고, 눈을 깜빡이고, 말할 때 입이 움직이며, 감정에 따라 끄덕이거나 팔짱을 낍니다. 헤더 버튼으로 채팅 화면과 전환할 수 있습니다.
- **다시 말하기**: 음성 인식이 잘못됐다면 보낸 메시지 아래의 "↩ 다시 말하기"로 그 턴 전체(상대 답변, 목표, 기분, 턴 수)를 되돌리고 바로 다시 말할 수 있습니다.
- **빠른 응답**: 서버가 상대 대사를 먼저 스트리밍하고 채점은 뒤이어 보내므로, 채점을 기다리지 않고 바로 대사를 듣습니다.
- **힌트**: 막히면 다음에 할 말 3가지를 난이도순으로 제안 (보상이 조금 줄어듦)
- **듣기 연습 모드**: 자막을 숨기고 탭해야 보이게 설정 가능
- **기억**: 다시 만난 캐릭터는 지난 대화를 기억합니다.

### 듣기·말하기 훈련
- **발음 연습(따라 말하기)**: 상대 대사·교정 문장·추천 표현 옆의 🎙 버튼 → 따라 말하면 단어별로 들린 단어(초록)와 안 들린 단어(빨강)를 표시하고 점수를 매깁니다. 채점은 기기에서 이뤄져 추가 비용이 없습니다.
- **전화 미션**: 휴대폰 "전화" 앱에서 레스토랑 예약, 피자 주문, 진료 예약, 인터넷 고객센터에 전화합니다. 얼굴이 안 보이고 자막도 기본으로 꺼져 있어 가장 현실적인 듣기 연습입니다. 걸어 다니다 보면 사촌 레오의 안부 전화나 보이스피싱 전화가 오기도 합니다.
- **택시 음성 길안내**: 택시 알바 중 일부 손님은 내비 대신 말로 길을 알려 줍니다. 운전하면서 들어야 하고, 못 알아들으면 `Q`나 버튼으로 "Left or right?", "Sorry, again?", "How far is it?"처럼 되물을 수 있습니다. 한 번도 안 헤매면 듣기 보너스를 받습니다.
- **엿듣기 퀴즈**: 👂 표시가 붙은 두 행인에게 다가가면 둘의 대화가 들리고, 끝나면 듣기 퀴즈가 나옵니다(정답 시 $25 + XP).
- **행인과 스몰토크**: 아무 행인에게나 `E`로 말을 걸어 자유 대화를 할 수 있습니다.
- **거리의 목소리**: 행인의 외침과 말풍선이 소리로도 들립니다(설정에서 끌 수 있음).

### 개인화
- **약점 맞춤 연습**: 대화가 끝날 때 AI 선생님이 반복되는 실수(관사, 과거 시제, 질문 어순 등 14가지)를 기록합니다. 이후 대화에서는 상대가 그 부분을 연습할 기회를 자연스럽게 만들고, 채점도 그 부분을 중점적으로 짚어 줍니다.
- **코칭 전화**: 통계 앱이나 전화 앱에서 클라라 코치에게 전화하면 내 약점에 맞춘 짧은 연습을 합니다.
- **표현집 + 간격 반복 복습**: 저장한 표현을 라이트너 방식으로 말하기 복습
- **통계**: 문법·어휘·유창성·발음 점수, 추정 CEFR 레벨, 연속 학습일

## 시작하기

### 요구 사항
- Node.js **20.12 이상**
- OpenAI 호환 Chat Completions API 키 (OpenRouter 권장)
- 음성 인식은 **Chrome** 계열 브라우저를 권장합니다. 음성 인식이 없는 브라우저에서도 타이핑으로 플레이할 수 있습니다.

### 설치 및 실행

```bash
npm install
```

```bash
cp .env.example .env.local
```

`.env.local`에 API 키를 넣은 뒤:

```bash
npm run dev
```

웹은 http://localhost:5173, API 서버는 8787 포트에서 실행됩니다. Vite가 `/api` 요청을 API 서버로 프록시합니다.

### 환경 변수

| 변수 | 설명 | 기본값 |
|---|---|---|
| `OPENAI_API_KEY` | AI 대화용 API 키 (없으면 대화 불가) | — |
| `OPENAI_BASE_URL` | OpenAI 호환 엔드포인트 | `https://api.openai.com/v1` |
| `OPENAI_MODEL` | 사용할 모델 | `openai/gpt-oss-20b` |
| `CHAT_DAILY_LIMIT` | 클라이언트당 하루 대화 턴 제한 (0 = 무제한) | `0` |
| `TTS_API_KEY` | (선택) 뉴럴 캐릭터 음성용 키. 없으면 브라우저/기기 음성 사용 | — |
| `TTS_BASE_URL` | (선택) OpenAI 호환 `/audio/speech` 엔드포인트 | `https://api.openai.com/v1` |
| `TTS_MODEL` | (선택) TTS 모델. `gpt-4o` 계열은 캐릭터별 억양 지시를 지원 | `gpt-4o-mini-tts` |
| `PORT` | API 서버 포트 | `8787` |
| `CORS_ORIGINS` | 추가 허용 CORS 오리진 (쉼표 구분) | — |
| `VITE_API_BASE_URL` | (Android 빌드) 배포된 API 서버 주소. `.env.android`에 설정 | — |

API 키는 서버에만 있고 클라이언트 번들에는 절대 들어가지 않습니다.

## 배포

`npm run build` 후 `npm start` 하나로 API와 웹 앱을 함께 서빙합니다. 운영 환경에서는 HTTPS 뒤에 두세요(마이크 권한과 Android 앱 모두 HTTPS가 필요합니다). 스트리밍 응답(`/api/conversation/turn/stream`)을 쓰므로 리버스 프록시에서 응답 버퍼링을 끄는 것이 좋습니다.

### Android

```bash
npm run android:add
```

```bash
npm run android:sync
```

```bash
npm run android:open
```

- `android:add`는 처음 한 번만 실행합니다.
- `.env.android`에 `VITE_API_BASE_URL`(배포된 HTTPS API 주소)을 설정한 뒤 `android:sync`로 빌드·동기화하고, `android:open`으로 Android Studio에서 엽니다.
- Android WebView에는 Web Speech API가 없어 음성 인식·TTS는 Capacitor 네이티브 플러그인을 사용합니다. 실기기에서 꼭 확인하세요.

## 프로젝트 구조

```
src/
├─ shared/            클라이언트·서버 공용 (DOM/Node API 없음)
│  ├─ api.ts          HTTP 계약 (zod 스키마 = AI 구조화 출력 스키마)
│  ├─ rules.ts        점수·보상·레벨·간격 반복·발음 채점
│  ├─ types.ts
│  └─ content/        시나리오, 캐릭터, 스토리, 전화, 엿듣기 대화, 약점 목록, 도시 장소
├─ server/            Hono API 서버
│  ├─ app.ts          라우트 (turn, turn/stream, hint, debrief, tts, health)
│  ├─ prompts.ts      프롬프트 빌더와 출력 정제
│  ├─ llm.ts          OpenAI 호환 구조화 출력 클라이언트 (재시도 포함)
│  ├─ tts.ts          뉴럴 음성 프록시 (캐릭터별 목소리, 캐시)
│  └─ rateLimit.ts
└─ client/            React 19 + Canvas 2D 게임
   ├─ game/           엔진, 도시 생성, 차량·보행자·교통·경찰, 디렉터(이벤트·알바), 렌더러
   ├─ conversation/   대화 상태 머신(스트리밍·되돌리기), 음성 입력
   ├─ audio/          효과음, 캐릭터 음성(뉴럴/기기), 립싱크 레벨
   ├─ platform/       웹 / Android(Capacitor) 차이를 감추는 추상화
   ├─ state/          세이브(버전 관리·마이그레이션), 진행 상황, UI 상태
   └─ ui/             화면, HUD, 휴대폰 앱, 대화 화면(1인칭 씬·통화·채팅)
```

### 설계 원칙
- **클라이언트는 ID와 학습자의 말만 보냅니다.** 프롬프트에 들어가는 장면·캐릭터·약점 설명은 모두 서버 쪽 콘텐츠에서 가져오고, 런타임 컨텍스트(경로, 주문, 지역 등)도 서버에서 검증된 값만 받습니다. 약점 역시 고정된 ID 목록으로만 주고받습니다.
- **대사와 채점을 분리합니다.** 캐릭터 대사와 채점을 두 개의 병렬 AI 호출로 나눠 목표 달성 판정 정확도를 높였고, 스트리밍으로 대사를 먼저 전달합니다.
- **모델은 제안하고 서버가 결정합니다.** 점수·기분 변화·목표 ID는 서버에서 범위를 제한하고 검증합니다.
- **도시는 결정적입니다.** 같은 시드에서 모든 기기가 같은 도시를 생성합니다.

## 개인정보

- 음성 인식은 브라우저/기기의 음성 서비스를 사용합니다.
- 대화 텍스트는 AI 응답과 피드백을 위해 서버로 전송됩니다. 뉴럴 음성을 켜면 캐릭터 대사 텍스트가 TTS 제공자로 전송됩니다.
- 진행 상황은 이 기기에만 저장됩니다.
